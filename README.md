# EJST Volume 6 (2026) Archive

Static, GitHub Pages-ready archive containing 28 article records, 4 issue pages, individual article pages, searchable metadata, and original PDF files.

## Publish
1. Extract this ZIP.
2. Upload the contents of the `EJST_Volume6_Archive` folder to the root of `ejst-journal/ejst-journal.github.io` (not the enclosing folder).
3. Choose **Commit directly to the main branch**.
4. Wait for GitHub Pages deployment, then test the site.

Search covers title, authors, DOI, extracted abstract, and extracted keywords. Abstract/keyword extraction is automatic and should be proofread against the PDFs before treating the archive as final. All original DOI strings and PDF page ranges are preserved; Issue 1 Article 7 uses the revised 84–95 PDF.
